Fill this in per book and give the **same file** to every translator working in
parallel. The whole point is that fourteen sections translated by fourteen
different passes still read like one book.

## 2. 翻译原则（信 · 达 · 雅的判据）

- **信**：不增不减。英文里的限定词（not / only / even / never / rather than）必须落地；数字、年份、人名、书名不得改动；引文要么照通行中译，要么自译并保持语气。
- **达**：中文读者读一遍就懂。允许为了通顺调整语序、断句、合并短句；不允许为了通顺删掉信息。
- **雅**：保留原文的语体差异——叙事段落要有画面和节奏，论述段落要清楚，军队/行业行话要有行话味。不添加原文没有的抒情与评价。

具体禁令：
- 不用欧化句式直搬：「在……的时候」→「……时」；「对于……来说」能省则省；「做出了……的决定」→「决定」；「被」字句只在真需要被动时用。
- 不要「进行 + 名词」这种虚化动词（进行了解 / 进行分析），直接说「了解 / 分析」。
- 不用「不仅仅是……而且」这类堆叠，直接说「不只是……」。
- 长句超过 200 字（中文）且读起来喘不过气，可以在不增删内容的前提下断句。

## 3. 标点与体例

- 引号一律中文弯引号：`“ ”`、`‘ ’`（不得出现 ASCII `"` `'`）。
- 破折号用 `——`（占两个汉字位）；省略号用 `……`。
- 书名、剧名、篇名用书名号 `《 》`；原文为斜体的术语用 `*…*` 标记，不要自己加书名号。
- 第一次出现的专有术语：`中文（English）`。**同一术语只在本章首次出现时加括注**，重复出现不再加。
- 中文与英文/数字之间加一个半角空格（如 `AI 的局限`、`1892 年`）。
- 引号嵌套：外层 `“ ”`，内层 `‘ ’`。

## 5. 标记格式（最重要）

输入文件每行一个语义块，行首可能带标记。**译文必须逐行对应**：

- 行数、行序、行首标记与英文源文件**一一对应**；标记本身不翻译。
- `%%BREAK%%`、`%%FIG%% <文件名>`、`%%CHAPNUM%%` 原样输出。
- 不得把两行合成一行，也不得把一行拆成两行。
- 需要给无图注的插图补图注时，**新增**一行 `%%CAP%% …`（不计入对应关系，允许）。
- 标记含义见 `references/markers.md`。

## 6. 自检（提交前必做）

1. 非空行数 == 英文源文件非空行数；标记序列完全一致。
2. 汉字数 ÷ 英文词数 落在 **1.5–2.0**（太低=漏译，太高=自行扩写）。
3. 每一行都含汉字（除 `%%BREAK%%` / `%%FIG%%` / `%%CHAPNUM%%` 这类）。
4. 中文行内不得残留英文单词（术语按第 4 节处理除外）。
5. 引号、括号成对；无重复标点。
